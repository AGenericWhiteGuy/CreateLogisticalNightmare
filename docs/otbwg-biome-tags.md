# Oh The Biomes We've Gone — Biome Tag Reference

Source: [Potion-Studios/Oh-The-Biomes-Weve-Gone](https://github.com/Potion-Studios/Oh-The-Biomes-Weve-Gone), `1.21.1` branch, generated datapack (`worldgen/biome` and `tags/worldgen/biome`).

55 biomes total, all Overworld (no Nether/End biomes in this mod).

## Tag categories

- **climate/**: `cold`, `dry`, `hot`, `temperate`, `wet`
- **density/**: `dense`, `sparse`
- **terrain type**: `forest`, `jungle`, `swamp`, `desert`, `savanna`, `plains`, `beach`, `badlands`, `mountain`, `peak`, `slope`, `wasteland`, `ocean`
- **flavor/feature**: `coniferous`, `taiga`, `floral`, `magical`, `icy`, `snowy`, `dead`, `windswept`, `sandy`, `sharpened_rocks`, `dripstone_arch`, `red_rock_arch`, `lush_arch`, `ironwood_gour_plateau`, `large_cold_lake`
- **has_structure/**: per-biome structure tags (villages, manors, trials, etc.)
